使用 `git diff --binary v0.1.177..v0.1.178` 生成上游增量，再对当前二开工作树执行 `git apply --3way`。这样非重叠文件直接吸收上游更新，重叠文件保留三方上下文，避免把二开代码整体替换为上游版本。

本次上游增量涉及后端 Ent schema/生成代码、迁移、渠道监控和供应商服务、OpenAI/Codex 网关，以及前端账号、渠道、监控和设置页面；共应用 297 个文件。
