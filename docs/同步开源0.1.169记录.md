## 二、同步方式和原则

本地仓库包含已上线二开提交，且本地历史不是上游标签的直接祖先关系，因此只以上游相邻标签的树差异作为同步输入：

```bash
git diff --binary --full-index v0.1.168..v0.1.169
git apply --3way --index
```

处理原则：

1. 只同步 `v0.1.168` 到 `v0.1.169` 的上游增量，不覆盖本地完整目录。
2. 已上线的鉴权、计费、免费分组、对话站、Grok、LobeHub SSO、兑换码和品牌功能优先保留。
3. 上游安全修复必须覆盖本地扩展出来的全部等价入口，不能因兼容路由留下绕过点。
4. 构建和部署改动同时满足上游运行时要求与本地非 root、跨架构和缓存优化。
5. 本次不创建提交、不推送远端、不操作生产服务。

## 三、引入的主要上游变化

- 收紧转发到上游的 URL 路径片段校验，修复 Responses 和 Gemini 兼容路径可能被恶意子路径改变的问题。

- Qwen3Guard 接受辅助分类字段，Claude Code 分类器兼容更多合法返回结构。
