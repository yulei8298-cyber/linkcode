## 二、同步方式和原则

本地仓库包含已上线二开提交，不能直接用上游代码覆盖。此次以上游两个标签的完整树差异作为输入：

```bash
git diff --binary --full-index v0.1.166..v0.1.168
git apply --3way --index
```

处理原则：

1. 已发布的本地迁移不可覆盖、改名或修改内容。
2. 上游功能与二开功能可以共存时合并双方实现。
3. 无法兼容时优先保留已上线二开行为。
4. 鉴权、计费、免费额度、对话站来源校验、Grok 路由和返利成本属于高风险区域，必须保留并通过回归测试。
5. Wire 生成代码根据最终依赖图重新生成，不长期手工维护生成文件。
